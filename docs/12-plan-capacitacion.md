## 1. INTRODUCCIÓN Y PROPÓSITO

### 1.1 Propósito del Documento
Este documento define la estrategia de capacitación y adopción para el sistema SIGMA-T, asegurando que todos los usuarios (administradores, jefes de operaciones, agencias de envíos, choferes y clientes) puedan utilizar el sistema de manera efectiva y eficiente, incluyendo las nuevas funcionalidades de **VRPTW v3.0**, **optimización de combustible**, **reoptimización dinámica**, **sistema de IA** y **análisis post-ruta**.

### 1.2 Objetivos de Capacitación
1. **Reducir la curva de aprendizaje:** Choferes <2 horas, Administradores <4 horas.
2. **Asegurar adopción temprana:** 100% de los usuarios capacitados antes del lanzamiento.
3. **Minimizar errores:** Reducir errores operativos en >80% en las primeras 2 semanas.
4. **Generar feedback temprano:** Recopilar sugerencias de mejora durante el piloto.
5. **Crear cultura de uso:** Fomentar el uso continuo del sistema mediante incentivos.
6. **🆕 Capacitar en nuevas funcionalidades:** VRPTW v3.0, reoptimización, IA y análisis post-ruta.

### 1.3 Audiencia
- **Líder del Proyecto:** Para aprobar la estrategia y recursos de capacitación.
- **Equipo de Desarrollo:** Para entender el material de capacitación que deben apoyar.
- **Stakeholders:** Para conocer el plan de adopción y sus roles.
- **Usuarios:** Para saber qué esperar de la capacitación.
